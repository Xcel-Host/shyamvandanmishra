# Setup

Two files, no build step. Push both to a repo and turn on GitHub Pages
(Settings → Pages → Deploy from branch → root), or open `index.html`
directly to preview locally.

## Before it's fully live, add these two files

```
assets/middle-east-tracker.png       screenshot of the tracker
assets/defense-intel-dashboard.png   screenshot of the dashboard
assets/cv.pdf                        your CV, for the download button
```

Until they're added, the project screenshots fall back to a labelled
placeholder box and the CV button links to a file that doesn't exist yet —
both self-resolve the moment you drop the real files into `assets/`, no
code changes needed.

No headshot is used — the design brief calls for no imagery outside the
projects section, so the page is intentionally text-led.
